# 🐾 Cutie Dotfiles

Welcome to **Cutie Dotfiles!** This repository contains the configuration files I use to personalize my system. For the sake of organization and maintainability, different distributions and management tools are kept in separate branches.

*Please select the branch appropriate for your system:*

* **Branch:** `nix-main`

## 🎩 Fedora & Other Distros (GNU Stow)
*Dotfiles managed with **GNU Stow** for Fedora and other traditional distributions.*

* **Directory Structure:** *Symlink-based (Stow)*
* **Branch:** `stow`
